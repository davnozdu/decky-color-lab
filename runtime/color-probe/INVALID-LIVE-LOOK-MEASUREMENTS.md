# Invalid static-look performance comparisons

Discovered 2026-11-17: gamescopectl forwards only argv[1] (command) and argv[2] (one value) through gamescope_private.execute. The prior call `gamescopectl set_look g22 PATH` silently ignored PATH and attempted to load a file named g22, clearing the LUT. Thus old off/on comparisons did not compare an active look with no look. Their frame/battery numbers are preserved as raw observations but cannot establish LUT cost, FPS loss or energy use. This affects live-look-20261116-200454 and the earlier live-look comparison, plugin builds 0.1.0/0.2.0 and the original live-look claims. Pure neural benchmarks and offline numerical model comparisons are unaffected.

Correct CLI: `gamescopectl set_look PATH`. Clear Gamma22 only: `gamescopectl set_look /dev/null`. Source src/Apps/gamescopectl.cpp Execute and src/wlserver.cpp gamescope_private_execute establish this behavior. The user confirmed a green diagnostic LUT had no effect with the old command and became visibly green with the corrected command. Ordinary look was restored and plugin 0.2.1 installed with the fix. Re-measure actual active filter cost before drawing performance conclusions.
